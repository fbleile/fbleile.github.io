A kernel-sensitive measure of stationarity

The SKDS compares an empirical sample with the stationary distribution induced by a stochastic differential equation. This small explorer uses the one-dimensional Ornstein–Uhlenbeck diffusion

$$dXt = -Xt\,dt + \sqrt{2}\,dW_t,$$

whose stationary distribution is standard normal. The points below are the sample. Click an empty part of the plot to add a point; click a point to remove it.

Linear SKDS estimate1.27298 points · click to add/remove

The displayed value is the linear SKDS estimator, following the implementation in the SKDS repository. The browser implementation mirrors its RBF, tilted RBF, and IMQ kernels and applies the one-dimensional Stein operator twice.

Why the kernel matters

Different kernels emphasize different relationships between observations. Changing the kernel or its bandwidth changes the geometry used to measure the discrepancy, while changing the points changes the empirical distribution being compared with the diffusion’s stationary law.
